# Add Agents to Gemini Enterprise

## Data

20/11/2026

## Objetivo

Integrar agentes ao Gemini Enterprise.

## Ferramentas utilizadas

- Gemini Enterprise
- Vertex AI
- Agent Engine
- OAuth
- Google Identity

## Aprendizados

### Agent Runtime

Ambiente onde o agente executa.

### OAuth

Mecanismo de autorização.

### Vertex AI Agent Engine

Plataforma de deploy e gerenciamento de agentes.

## Dificuldades encontradas

- OAuth
- Encontrar Resource Path
- Navegação no Vertex AI

## Solução

Agent Runtime encontrado através do Vertex AI Agent Engine.

## Aplicação prática

Agentes corporativos para consulta de métricas e indicadores de negócio.
